# Site Web ImaginK' - Documentation

## 🎉 Statut : Prêt à démarrer !

Le site web est configuré et prêt. Voici ce qui a été créé :

## 📁 Structure du projet

```
site_frontend/
├── src/
│   ├── components/
│   │   ├── Navbar.jsx          # Navigation responsive
│   │   ├── HeroSlider.jsx      # Carrousel hero avec 3 slides
│   │   ├── Manifesto.jsx       # Section manifeste
│   │   ├── BentoGrid.jsx       # Grille de services moderne
│   │   ├── Metrics.jsx         # Chiffres clés animés
│   │   └── Testimonials.jsx    # Témoignages clients
│   ├── pages/
│   │   └── Home.jsx            # Page d'accueil complète
│   ├── data/
│   │   └── content.js          # Tout le contenu du site
│   ├── App.jsx                 # Router principal
│   ├── main.jsx                # Point d'entrée
│   └── index.css               # Styles globaux + couleurs brand
└── public/
    └── logo.png                # Logo ImaginK'
```

## 🚀 Commandes

```bash
# Démarrer le serveur de développement
npm run dev

# Compiler pour la production
npm run build
```

## 📝 Contenu proposé inclus

- Hero Slider (3 slides)
- Services (6 cartes)
- Métriques (4 chiffres clés)
- Témoignages (4 clients)
- Manifeste

Tous les contenus sont modifiables dans `src/data/content.js`.
